# Spirit Draft · Spirit Island

Piccolo sito statico per estrarre senza duplicati gli Spiriti principali di Spirit Island.

## Pubblicazione gratuita con GitHub Pages

1. Crea un account su [GitHub](https://github.com), se non ne hai già uno.
2. Crea un nuovo repository pubblico chiamato, ad esempio, `spirit-island-draft`.
3. Carica in quel repository **il contenuto** di questa cartella: `index.html`, `style.css`, `app.js` e `README.md`.
4. Nel repository apri **Settings → Pages**.
5. In **Build and deployment**, scegli **Deploy from a branch**; seleziona il branch `main` e la cartella `/(root)`, poi premi **Save**.
6. Dopo uno o due minuti GitHub mostrerà l'indirizzo pubblico del sito, nella stessa pagina. Avrà una forma simile a `https://tuo-utente.github.io/spirit-island-draft/`.

Non serve installare dipendenze: è un normale sito HTML, CSS e JavaScript.

## Anteprima sul proprio computer

Apri `index.html` nel browser oppure, da questa cartella, avvia:

```bash
python3 -m http.server 8000
```

e visita `http://localhost:8000`.
